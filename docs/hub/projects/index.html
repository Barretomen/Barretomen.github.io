Operations Command Assistant

Um ambiente Electron que reúne automações antes espalhadas por extensões e páginas.

O crescimento de pequenas automações tornou o navegador pesado e o trabalho fragmentado. A solução evolui essas ferramentas para uma aplicação desktop com navegação integrada, sessão persistente e módulos operacionais reutilizáveis.

  • Electron
  • JavaScript
  • Python
  • CDP
  1. Base desktopElectron integrado a um sidecar Python.
  2. Sessões persistentesNavegação interna e autenticação preservada.
  3. Módulos operacionaisFluxos de captura, consulta e preenchimento reunidos.
  4. Arquitetura modularConsolidar integrações e reduzir dependências entre fluxos.
  5. Qualidade e distribuiçãoTestes automatizados e atualização controlada.

  • .NET 8
  • WinForms
  • Windows API
  1. Gerenciador de janelasDetecção e troca rápida entre personagens.
  2. Experiência desktopCards, temas, tray e startup.
  3. Modo multicontaBroadcast controlado de mouse e teclado.
  4. Perfis de configuraçãoConjuntos reutilizáveis por composição.

  3. Validação assistidaConferência antes de qualquer emissão.
  4. Fluxo pós-emissãoDownload e organização do documento.
  5. Auditoria mensalConferência de duplicidade e histórico.
