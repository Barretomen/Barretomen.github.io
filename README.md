# barretomen.github.io

O meu site pessoal e portfólio, publicado com GitHub Pages.

Inclui o portfólio em formato RPG, o João Hub e algumas páginas de projetos. Foi feito com HTML, CSS e JavaScript, sem framework ou processo de build.

[Abrir o site](https://barretomen.github.io/)

Para testar localmente, basta abrir `index.html`. Algumas funções do Hub que consultam a API do GitHub funcionam melhor através de um servidor local:

```bash
python -m http.server 8000
```
